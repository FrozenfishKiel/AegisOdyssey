# Memory

## 作用

`Memory` 解决的是“这次任务学到的东西，能不能留到下次”。

如果没有这一层，AI 每次任务都会重新进入新手模式。

Memory 在这套能力包里的职责是：

- 把稳定规则沉淀下来
- 把重复踩坑记录下来
- 把这次任务形成的可复用结论留给下次

## Memory 不是聊天记录

这里的 Memory 不是：

- 聊天窗口自动累积的对话
- 某次任务结束后的即兴总结
- 只在当前会话里短暂出现的说明

这里的 Memory 应该是稳定存在、下次会被再次读取的工程资产。

## UE 场景里的最小 Memory 载体

在当前场景里，Memory 至少应落在这些稳定文件中：

- 规则文件
- 任务流程文件
- 技术文档模板
- 测试文档模板
- 任务记忆日志
- 可复用的协作规范

## Memory 和 Notice 的边界

Memory 不应和阶段性交接混在一起。

- 稳定、可复用、下次仍成立的内容，应进入长期记忆或知识沉淀
- 当前轮次背景、阶段性判断、临时提醒，应进入 `Notice`

一句话判断标准仍然是：

“这句话半年后还应该成立吗？”

## 和自循环的关系

Memory 只有进入“下次默认再次读取”的链路里，才是真正的 Memory。

否则它只是一次性的产物，不是 Harness 的长期记忆层。
