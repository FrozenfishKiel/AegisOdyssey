### 滑步处理
#### Animation Warping插件
这是一个专门用于动画扭曲（Animation Warping）的插件，主要用于修改动画的根运动（root motion）来实现角色移动的精确控制

![](https://cdn.nlark.com/yuque/0/2025/png/57222916/1765268712159-50f84ab7-faed-447e-989e-49bc1a1444c2.png)

##### 一、Stride Warping步幅匹配
使用Stride Warping并选中图标（Graph）模式，然后输入我们当前的移动速度，Stride Warping节点是一个 _**步幅扭曲**_ 节点，专门用于_**调整角色行走/奔跑动画的步幅长度**_，让_**动画速度与角色实际移动速度相匹配**_。

1. 解决滑步问题

- 问题 ：角色移动速度变化时，动画步幅不变，导致脚部滑动

- 解决方案 ：动态调整动画步幅，匹配实际移动速度 2. 提升动画真实感

- 让角色的行走/奔跑动画更加自然

- 适应不同地形和移动状态 3. 支持复杂移动场景

- 斜坡行走

- 加速/减速过程

- 不同速度的动画混合



1. 评估模式（Evaluation Mode）

位置 ： `EWarpingEvaluationMode`

 A. Graph模式（自动模式）

- 作用 ：自动从动画的根运动中获取移动数据

- 适用场景 ：使用根运动的动画

- 隐藏参数 ：StrideDirection、StrideScale

- 需要参数 ：LocomotionSpeed（角色的实际移动速度，Graph模式下自动计算扭曲比例）、MinRootMotionSpeedThreshold

- 作用 ：手动指定扭曲参数

- 适用场景 ：需要精确控制的场景

- 隐藏参数 ：LocomotionSpeed、MinRootMotionSpeedThreshold

- 需要参数 ：StrideDirection、StrideScale

工作原理 1. 数据收集阶段

- 获取动画的根运动数据

- 计算角色的实际移动速度

- 检测地形法线方向

 2. 扭曲计算阶段

- 比较动画速度与实际速度

- 计算需要的扭曲比例

- 考虑地形和重力因素

 3. 骨骼调整阶段

- 应用扭曲到脚部骨骼

- 调整骨盆位置

- 补偿大腿旋转

所以我们这里选择Graph模式

![](https://cdn.nlark.com/yuque/0/2025/png/57222916/1765269700182-536f1579-1c82-4d11-9bff-90cf32e4b159.png)

然后选择一个骨骼（通常是盆骨）进行扭曲，骨盆是人体骨骼系统的中心，所有腿部骨骼都连接到骨盆。在步幅扭曲计算中，骨盆位置作为参考点，用于计算腿部骨骼的相对位置和距离。当角色步幅发生变化时，骨盆需要相应地调整高度来保持脚部与地面的接触。如果没有骨盆骨骼，就无法实现这种自然的身体调整。

Alpha参数是Stride Warping节点（以及所有骨骼控制节点）的通用混合强度控制参数 ，它允许你精细控制步幅扭曲效果的强度，实现平滑的动画过渡和动态的效果调整。

![](https://cdn.nlark.com/yuque/0/2025/png/57222916/1765269935352-6437a070-2f89-49b3-9fa6-0e3bd62e7c24.png)

ALS或Lyra高级运动有一个限制就是你所使用的动画的人性骨骼要有IK支持

![](https://cdn.nlark.com/yuque/0/2025/png/57222916/1765270397851-6c7d48ae-bb81-48aa-a696-4d064a1e44a4.png)

所以这里我们要选择IK_Foot_Root，IK Foot Root Bone定义了地面平面的法线方向和重力方向，这是计算步幅扭曲的基础坐标系。这个骨骼帮助确定步幅扭曲发生的平面，确保扭曲效果符合物理规律

![](https://cdn.nlark.com/yuque/0/2025/png/57222916/1765270903024-41f716f6-dfb4-4947-863a-6becfd965d1d.png)

FootDefinitions是一个包含FStrideWarpingFootDefinition结构体的数组，每个结构体定义了一个脚部的三个关键骨骼：

```plain
// Foot definition specifying the IK/FK foot bones and Thigh bone
USTRUCT(BlueprintInternalUseOnly)
struct FStrideWarpingFootDefinition
{
    // IK driven foot bone
    FBoneReference IKFootBone;

    // FK driven foot bone
    FBoneReference FKFootBone;

    // Thigh bone, representing the end of the leg chain prior to reaching the Pelvis Bone 
    FBoneReference ThighBone;
};
```

###### 骨骼配置解析
###### 1. IK Foot Bone（IK驱动的脚部骨骼）
+ 作用 ：这是实际应用步幅扭曲效果的骨骼
+ 示例 ： IK_Foot_l （左脚IK骨骼）
+ 为什么需要 ：IK骨骼用于接收步幅扭曲计算的结果，直接控制脚部的位置和旋转

###### 2. FK Foot Bone（FK驱动的脚部骨骼）
+ 作用 ：这是原始动画中的脚部骨骼，用于参考和比较
+ 示例 ： foot_l （左脚FK骨骼）
+ 为什么需要 ：FK骨骼保存了原始动画的步幅信息，用于：
    - 计算原始步幅长度
    - 提供步幅扭曲的参考基准
    - 防止过度扭曲（通过FK限制）

###### 3. Thigh Bone（大腿骨骼）
+ 作用 ：作为腿部骨骼链的起点，连接骨盆和脚部
+ 示例 ： Thigh_l （左大腿骨骼）
+ 为什么需要 ：大腿骨骼是步幅扭曲计算的关键参考点，用于：
    - 确定步幅扭曲的起始位置
    - 计算腿部长度和角度
    - 协调骨盆和脚部之间的运动

![](https://cdn.nlark.com/yuque/0/2025/png/57222916/1765271187010-098507ca-d202-4e6d-8357-9dfe85b269dd.png)

这种三骨骼配置确保了步幅扭曲既精确又自然，避免了常见的滑步和漂浮问题

###### Orientation Warping节点概述
Orientation Warping节点是一个 方向扭曲动画节点 ，位于 `AnimNode_OrientationWarping.h` 文件中，它在蓝图中的显示名称为"Orientation Warping"。

###### 核心功能
根据 `AnimGraphNode_OrientationWarping.cpp` 第25行的工具提示，这个节点的主要功能是：

"Rotates the root and lower body by the specified angle, while counter rotating the upper body to maintain the forward facing direction."

翻译 ：按照指定的角度旋转根骨骼和下半身，同时反向旋转上半身以保持面向前方的方向。扭曲角度参数 (Orientation Angle)

+ 位置 ：第53行 float OrientationAngle = 0.f
+ 作用 ：指定相对于旋转轴的期望扭曲角度（以度为单位） 移动角度参数 (Locomotion Angle)
+ 位置 ：第60行 float LocomotionAngle = 0.f
+ 作用 ：角色移动角度，用于计算方向扭曲： Orientation = RotationBetween(RootMotionDirection, LocomotionDirection) 移动方向向量 (Locomotion Direction)
+ 位置 ：第67行 FVector LocomotionDirection = { 0.f, 0.f, 0.f }
+ 作用 ：世界空间中的角色移动方向向量



根据 `AnimNode_OrientationWarping.cpp` 的实现：

1. 方向计算 ：计算根运动方向与期望移动方向之间的角度差异
2. 身体扭曲 ：下半身按照计算的角度进行旋转
3. 反向补偿 ：上半身进行反向旋转以保持面向方向
4. 平滑过渡 ：通过插值速度实现平滑的角度过渡
